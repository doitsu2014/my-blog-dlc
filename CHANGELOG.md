# Changelog

All notable changes to my-blog-dlc are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - Initial release

Derived from [my-aidlc](https://github.com/doitsu2014/my-aidlc) 0.1.0: the
engine, packaging, harness projections, and protocols are carried over; the
methodology is rewritten for blog writing.

### Added

- Six phases — Discover, Outline, Draft, Refine, Publish, Evolve — and 20
  stages with approval gates.
- Seventeen agents: composer, content strategist, audience analyst,
  researcher, SEO specialist, outline architect, copywriter, writer,
  technical author, visual designer, developmental editor, technical
  reviewer, fact checker, copy editor, publisher, distribution strategist,
  and content analyst.
- Seven workflow profiles with keyword auto-detection: `classic`, `quick`,
  `tutorial`, `deep-dive`, `opinion`, `refresh`, and `repurpose`.
- Four reference skills: `editorial-style`, `technical-writing`,
  `seo-onpage`, and `platform-publishing`.
- Blog-oriented memory templates: editorial standards (org), review and
  distribution practice (team), and audience, voice, style, and platform
  contract (project).
- Guardrails: `[TK]` / `[AUTHOR]` placeholders instead of fabrication; posts
  are packaged as drafts and never released by an agent, including in YOLO
  mode.
- Execution modes `normal` and `yolo`, a configurable question budget, an
  append-only audit log, parking and resume, `doctor`, `status`, and shell
  completion for bash, zsh, fish, and PowerShell.
- Harness projections for PI Agent (`/blogdlc`), Codex CLI (`$blogdlc`), and
  Claude Code (`/blogdlc`).
