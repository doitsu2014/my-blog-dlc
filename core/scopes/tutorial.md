# tutorial scope

`tutorial` is the profile for teaching the reader to do something: set up a
tool, build a feature, fix a class of problem. Readers copy tutorials into
their terminals, so code verification and technical review are the heart of
this profile.

## Why these stages

Discover pins the reader's starting point and the end state, and checks
search intent — tutorials are usually found through search. Outline chooses
a step-by-step structure. Draft writes the post and builds runnable,
version-pinned examples. Refine re-runs every example, fact checks versions
and claims, and proofreads. Publish packages and distributes.

Code Examples and Technical Review stay CONDITIONAL but almost always apply
here. Evolve is a separate intent: resume it with `classic` or start a
`refresh` when versions change.

## Membership

Discover, Outline, Draft, Refine, Publish: all stages.

Evolve is SKIP.
