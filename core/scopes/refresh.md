# refresh scope

`refresh` is a fast, evidence-driven path for updating a post that is
already published: fix an error, update versions, add a missing section, or
improve how it serves its query. It keeps the verification ceremony and
drops the planning ceremony.

## Why these stages

Brief Capture names the existing post and the change (often from a
`content-refresh` refresh plan). Keyword Research runs only when the refresh
targets search performance. First Draft revises the existing post in place
rather than starting blank. Fact Check verifies every changed claim. Copy
Edit proofreads and adds the "Updated on" note. SEO Optimization keeps the
slug stable. Publish Package rebuilds the post.

Promote the refresh to `tutorial` when code examples change substantially.

## Membership

Discover: brief-capture, keyword-research.
Draft: first-draft.
Refine: fact-check, copy-edit.
Publish: seo-optimization, publish-package.

Everything else is SKIP.
