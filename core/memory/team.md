# Team Memory

Rules for the team (or the solo author) that writes this blog. More specific
than organisation memory; a narrower rule here overrides a broader rule only
when it does not contradict it.

## Workflow

- Posts live in version control; one branch or pull request per post.
- Drafts stay marked as drafts until the author releases them.
- Reviews focus on the reader and correctness before style.

## Review

- Technical posts are reviewed by someone who runs the code.
- The author has the final word on voice; editors have the final word on
  facts.

## Distribution

- The author posts to social channels personally; no automated posting.
- Cross-posts always set a canonical URL back to the blog.
