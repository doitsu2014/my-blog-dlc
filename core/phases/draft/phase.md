# Phase 3 — Draft

Draft turns the approved outline into a complete post. Drafting is cheap;
the constraint is voice and truth. The draft must sound like the author, not
like a model, and every example must actually work.

## Focus

Writing.

## The AI's role

Writing partner. The model drafts from the outline and the author's voice
notes in project memory, and marks every place where it is guessing. The
human owns the voice: a draft the author would not sign is not done.

## Outputs

- A complete draft that follows the approved outline
- Runnable, verified code samples (technical posts)
- An asset plan: diagrams, screenshots, cover image, alt text

## Gates

Every stage in Draft ends at a human approval gate.

## Exit criteria

- The draft covers every outline section, or records why a section moved
- The voice matches the style notes in project memory
- Every code sample was executed and its output recorded
- Every planned visual has a purpose and alt text

## Next phase

When Draft is approved, [Refine](../refine/phase.md) edits structure, checks
facts and code, and polishes the language.
